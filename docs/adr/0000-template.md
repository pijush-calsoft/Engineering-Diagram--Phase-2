How to use this template:

- Copy this file to `NNNN-short-title.md` with the next free number, and add a row to [README.md](README.md).
- Every fact, number, tool or licence carries a citation: "plan §N", "plan Phase N" or "deck slide N".
- If neither source gives something, write it under **Open items** ("Not specified in plan or deck; see OD-x" or "TBD in Phase 0"). Do not fill the gap with a guess.
- Where plan and deck disagree, the plan is the baseline. Record the deck position with its slide and its D/I/L id from [plan-vs-deck.md](../reference/plan-vs-deck.md).
- A new ADR starts as **Proposed**. It becomes **Accepted** only when the deciding owner signs off; record the owner role and date in [open-decisions.md](../open-decisions.md).
