# Block 1: Drawing Parser

**Status: Phase 2 inputs built** for DXF, DWG, vector PDF, STEP, IGES and STL. Scans wait for the multimodal path (ADR-0007, OD-43). Registered as `b1_parser` through the `edp.blocks` entry point (plan §3).

Output: `geometry` artifact (schema 0.2.0), written to the Data Fabric's cleaned zone (deck slide 30). Every entity, title-block field, hole and solid carries a source locator.

## By input

| Input | Method | Locator `handle` | Module |
|---|---|---|---|
| DXF | ezdxf `recover.read` (CRLF, encodings, damaged files); layouts, inserts, polylines; DIMENSION displayed value, measurement and measured points; title block. Invalid XDATA is stripped and dimensions with broken geometry blocks are read from their own tags (`DXF_RECOVERED`) | DXF entity handle | `dxf.py`, `dxf_raw.py` |
| DWG | LibreDWG `dwg2dxf` as a separate process (GPLv3, plan §9), then the DXF path. Warnings become `DWG_CONVERSION` flags; no output is a blocking failure | DWG entity handle (kept by LibreDWG) | `dwg.py` |
| Vector PDF | pypdfium2: paths become lines, circles and arcs (fitted from Beziers); text runs become text; numbers (with Ø or R) become dimension values; units and scale from the title block | `p<page>/path-<n>`, `p<page>/text-<n>` | `pdf.py` |
| STEP, IGES | OCP: per solid, bounding box, volume, faces by surface type, edges; holes are full cylinders around an axis outside the material | STEP `#<entity>`, IGES `DE<number>` | `model3d.py` |
| STL | trimesh: bounding box, watertightness, volume, through-opening hint (genus); flagged `LOSSY_INPUT`, and unit-less | `mesh` | `model3d.py` |
| Scans, images (PNG, JPEG, TIFF; PDFs whose pages hold only images) | OpenCV median filter and deskew, then gpt-5.5 reads title block, dimensions and notes with boxes through the Model Gateway (ADR-0007); boxes and numbers checked in code and mapped back onto the original image | `p<page>/dim-<k>`, `p<page>/note-<k>`, `p<page>/tb-<field>`; bbox in image pixels, y up | `scan.py` |

## Drawings with nothing to read (OD-62)

A 2D drawing (DXF, DWG, PDF, scan) with no dimension entity is flagged for review, so the run stops at block 1 instead of going on with an empty result (`annotations.py`). 3D models are not checked.

| Flag | When | Message hints at |
|---|---|---|
| `EMPTY_DRAWING` | no entity was read | |
| `NO_DIMENSIONS` | entities but no dimension; text present | values written as plain text are not taken as dimensions |
| `NO_DIMENSIONS` | entities, no dimension and no text | lettering drawn as outlines, with the count of skipped HATCH entities; export again with text and dimensions kept, or read as a scan |

Found with a plan and a section exported as DXF from an open-source BIM tool, which writes lettering as hatches and dimensions as lines.

**These sets are easy for this parser.** They are generated by this repository, the PDFs by a simple writer (Helvetica, whole-word text), the DWGs by converting the DXF set. Real CAD exports split text into characters, draw text as outlines, use dashed and hidden lines, and come from many CAD tools. Phase 2 targets for STEP/IGES/STL are not set in the plan (TBD-AC-1).

## Known limits

- **PDF dimensions have no measured points**, so block 2 cannot link them to features geometrically; PDF outlines are plain paths, so holes get no datum. Interpretation for PDF input is a follow-up (phase-3 log).
- **Scans** read text only: no lines or circles yet (plan: "line and circle detection"), so block 2 finds no features on a scan. Small digits are misread at 150 DPI, and some boxes land more than two text heights from the text. Client scans are refused until title-block masking exists (OD-51). Each page costs about 0.10 USD (OD-53).
- **3D inputs**: block 2 does not build features from 3D topology yet (plan Phase 3 task 2, "from 3D topology").
- **LibreDWG 0.14** is the converter (0.11 as fallback, OD-49). The DWG test set is written by LibreDWG itself, so it checks the round trip, not DWGs from commercial CAD tools.
- Dimension association and the confidence values are starting points to calibrate on real drawings (Phase 2 task 5, OD-45, OD-47).
